## 這個網站的性質

本站是公開的靜態文件網站。目前網站本身不提供使用者帳號、登入 session、付款功能，也沒有第一方應用程式資料庫。

## 網站分析

本站設定使用 Google Analytics。依瀏覽器與隱私設定而異，分析請求可能會把頁面瀏覽、瀏覽器／裝置資訊，以及由網路連線產生的技術資訊傳送給 Google。瀏覽器擴充功能、同意控制或平台層級的保護機制可能會阻擋這些請求。

## 其他外部資源

目前網站模板可能載入 GitHub Buttons 與 Mailchimp 的外部資源。載入第三方資源時，該服務可能取得一般 HTTP 請求中會出現的資訊，例如 IP 位址、瀏覽器標頭與來源頁面。

## 貢獻與下載

公開下載檔案由本站以靜態檔案提供。若前往 GitHub 或其他外部服務，將適用該服務自己的隱私規則。目前貢獻方式以 GitHub Issue 或 Pull Request 為主；請勿在公開 repository 討論中張貼密碼、金鑰或敏感個人資料。

## 資料保留邊界

本 repository 無法定義或控制 Google、GitHub、Mailchimp 或其他第三方服務的資料保留政策。若需要依賴特定的保留或刪除條件，應直接查閱各服務當時的正式政策。

## 變更原則

若未來新增表單、帳號、付款、私人投稿或其他追蹤工具，應在對外提供該功能前同步更新本頁說明。
